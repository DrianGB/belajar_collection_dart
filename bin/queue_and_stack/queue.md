# Queue 
    Adalah collection implement dari structur stack (tumpukan) atau Queue (Atrian)
    dan kedua ini disatukan,
# Queue Work
    bekerja dengan cara seperti antrian yaitu 
    _____________________________________
in  ##################################### out

(penambahan selalu dari belakang)
method nya .addLast()
dan untuk mengambil nya .removeFirst()

    jadi seperti antrian ada head(depan) dan tail(belakang)
    jika kita memasukan data dari belakang
    lalu ketika kita mengeksekusi kita akan melakukan dari kepala nya 
    sehingga 
    - data yang pertama masuk maka akan dieksekusi pertama kali
    - atau bisa di sebut first in first out 
    - saat diambil atau removeFirst maka akan menghapus data nya jadi ditampilkan sebari di hapus
