# Stack 
    Adalah collection data di dart yang menggunakan konsep penumpukan 
    contoh nya seperti ini: 
                                      In
    __________________________________
    |################################# 
    
                                      Out
    
    memasukan data .addLast() untuk menyimpan di belakang
    untuk mengambil data .removeLast() untuk mengambil yang ujung seperti stack

    sehingga secara fungsi hampir sama seperti stack namun di satukan dalam queue

    Penggunakan Stack itu mengunakan Queue di dart hanya tinggal mengganti parameter pengambilan nya saja

    sehingga memiliki konsep: 
    - last in (dimasukan paling akhir)
    - first out (dieksekusi paling awal)
